# Группы технологий

Табы обозначают направления будущих заказов и не зависят от текущего портфолио.
Данные групп, применимость и варианты по направлениям: `js/technologies-filter.js`.

- Дизайн и графика: Figma и Photoshop дополняют друг друга.
- Основа страницы: HTML и CSS работают вместе.
- Интерактив: JavaScript, TypeScript как вариант разработки с проверкой типов.
- Интерфейс: React или Vue. Next.js использует React, не является его заменой.
- CMS и фреймворки: варианты основы, а не обязательный совместный набор. WordPress/Joomla для контента, Shopify/WooCommerce для торговли, Laravel для собственной серверной логики, Next.js для React-приложений. Node.js обозначен как серверная среда, не CMS.
- Базы: MySQL, MariaDB, PostgreSQL, MongoDB. Выбираются по совместимости с основой и модели данных. Для WordPress/WooCommerce — MySQL/MariaDB, а не произвольная БД. Shopify не требует отдельной собственной БД.
- Игры: Phaser (2D), Three.js (3D), Canvas API (собственная 2D-отрисовка). Это разные уровни инструментов; не обязательный набор.

Лендинги и визитки показывают дизайн, основу страницы и интерактив. Корпоративные сайты добавляют основу проекта и БД. Магазины и приложения показывают также варианты интерфейса; они нужны по архитектуре. Сервер и БД для онлайн-игр обсуждаются отдельно.

Карточки обозначают возможные решения, не обещание использовать всё сразу. У инструментов есть разные роли: совместимость важнее буквального правила «один инструмент на проект». CMS и отдельный React-интерфейс могут сочетаться в headless-архитектуре.
Хостинг, облако и ИИ остаются отдельными поясняющими блоками.

Источники: https://www.joomla.org/about-joomla ; https://nextjs.org/docs ; https://wordpress.org/about/requirements/ ; https://shopify.dev/docs/storefronts/headless/overview

## Общие группы во всех направлениях

Git, GitHub/GitLab и CI/CD объединены в карточку процесса разработки. Хостинг/серверы: Vercel, AWS, VPS как варианты размещения. Облачные дополнения описаны внутри этой группы. ИИ-интеграции: Claude, Gemini, GPT, DeepSeek как варианты API, подключаемые по задаче, а не обязательные зависимости. Три отдельные сервисные карточки удалены. Пояснения расположены под сеткой. Высоты карточек равны в пределах каждой строки fitRows и пересчитываются при фильтрации и изменении ширины. По явному запросу подписи role имеют 10px, badge — 11px; названия технологий остаются 18px.

Уточнение применимости: «Код и CI/CD» показывается в магазинах, приложениях и браузерных играх; скрыт для лендингов, визиток и корпоративных сайтов. Базы данных доступны во вкладке игр как дополнительная серверная возможность для аккаунтов, прогресса, рейтингов и онлайн-функций.

ИИ-интеграции скрыты для лендингов, визиток и корпоративных сайтов; остаются среди вариантов для магазинов, приложений и браузерных игр, а также в общем списке.

Реклама и продвижение: YouTube, Google, Instagram, TikTok, Facebook, телевидение и газеты. Карточка доступна во всех направлениях как возможные каналы по аудитории, целям и бюджету. Это каналы продвижения, а не зависимости разработки.

Из карточки «Реклама и продвижение» удалены телевидение и газеты. В карточке остаются YouTube, Google, Instagram, TikTok и Facebook.
