# AURA ONE — два стиля одного сайта

Концептуальный аудиобренд используется только для демонстрации дизайна. Это не клиентский кейс Nexora.

- `aura-minimalism.png` — законченный дизайн сайта в стиле минимализм.
- `aura-maximalism.png` — тот же сайт, переоформленный в стиле максимализм.

Оба изображения созданы встроенным инструментом image_gen. Второе создаётся редактированием первого, чтобы сохранить продукт, содержание и расположение ключевых элементов.

Задание для минимализма: готовый скриншот магазина наушников AURA ONE формата 4:3, без рамки устройства и браузера. Светлый фон, сдержанные сиреневые акценты, чистая типографика, свободное пространство, реалистичная фотография серебристых наушников справа. Заголовок «Слышать больше.», подзаголовок «Ваш звук. Ваш ритм. Ничего лишнего.», кнопки «Выбрать AURA ONE» и «Узнать больше». Навигация «Наушники», «О бренде», «Поддержка». Три преимущества: «40 часов музыки», «Активное шумоподавление», «Комфорт каждый день». Ниже раздел «Созданы для вашего ритма» с фотографиями детали наушников, человека в наушниках и футляра. Никаких каркасных блоков, пустых плашек и плейсхолдеров.

Задание для максимализма: отредактировать минималистичный макет, сохраняя бренд, ту же модель серебристых наушников, их положение и масштаб, русские тексты, действия, разделы и основные координаты композиции. Изменить художественное исполнение: глубокий фиолетовый фон, электрические синие и фуксиевые градиенты, многослойные звуковые ленты за продуктом, стеклянные панели, орбитальная графика, выразительная типографика и драматичный свет. Те же три фотографии в нижнем разделе, насыщенная подсветка и тонкие рамки. Богатый, но читаемый законченный дизайн — не другой сайт и не прототип.
