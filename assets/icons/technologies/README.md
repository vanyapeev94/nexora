# Technology marks

Local SVG assets from [Devicon](https://github.com/devicons/devicon), downloaded from its `icons/` directory. The upstream license is included in `LICENSE.devicon`. Logos identify the technologies shown in Nexora's technology section.

Local filenames correspond to technology IDs. Upstream names differ for JavaScript (`javascript`), Vue (`vuejs`) and AWS (`amazonwebservices`). Devicon marks use the upstream `*-original.svg` variant. `canvas.svg` is an original project-native pictogram for the Canvas API, not a Devicon asset or an official brand logo. No runtime requests to a CDN are required. Marks not used by the current minimal profiles remain available as source assets.

`wordpress.svg`, `photoshop.svg`, and `threejs.svg` also come from Devicon. `shopify.svg` comes from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/shopify.svg), with a green fill applied; its license is in `LICENSE.simple-icons`. `phaser.svg` is an original project-native game-engine pictogram, not the official Phaser logo.

MariaDB, Angular: Devicon original SVG (MIT). Joomla: Simple Icons (CC0), brand blue fill. Sources: raw.githubusercontent.com/devicons/devicon/master/icons/ and raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/joomla.svg.

GitHub/GitLab: Devicon (MIT). Claude/Gemini: Simple Icons (CC0), brand colors. GPT/OpenAI and DeepSeek: lobehub/lobe-icons static-svg (MIT), LICENSE.lobe-icons. Server and CI/CD: original SVG pictograms.

Advertising icons ad-*.svg reuse the inline vector marks and pictograms from the project workflow animation.
