# Nexora

Многостраничный сайт IT-команды на HTML, CSS и JavaScript. Без сборки и внешних зависимостей во время работы сайта.

## Запуск

Откройте `index.html` или запустите `python -m http.server 8080` из папки проекта и перейдите на http://localhost:8080.

## Страницы и данные

- `index.html` — главная: сравнение двух стилей сайта, услуги, технологии, этапы, избранные работы, демо партнёров, команда, калькулятор.
- `portfolio.html` — все шесть работ с фильтрами.
- `project.html?id=board` — шаблон страницы проекта. Поддерживает все ID из данных.
- `blog.html` — список полезных материалов.
- `article.html?id=brief` — шаблон статьи.
- `js/data.js` — проекты и статьи. Для добавления работы или материала добавьте объект в соответствующий массив.
- `js/site.js` — общие меню и футер, рендеринг данных, интерактивные блоки, расчёт и скачивание сметы.
- `css/site.css` — общая система оформления и адаптивность.

Старые CSS/JS и библиотека Isotope сохранены как исходные материалы прототипа, но новыми страницами не подключаются.

## Логика калькулятора

Демонстрационная валюта — EUR. Базовые стоимости и доплаты находятся в `value` элементов калькулятора в `index.html`. Названия функций для расчёта — в `data-label`. Сумма = тип проекта + навигация + выбранные функции. Верхняя граница ориентира — сумма × 1,3 с округлением вверх/вниз до ближайших 50 EUR. Это демонстрационный запас оценки, а не согласованный бюджет.

Адаптивный дизайн, разработка и базовая проверка включены в основу. Домен, хостинг, контент, лицензии сервисов и поддержка указаны отдельно. Посетитель может скачать TXT с составом и описанием задачи. Данные не отправляются и не сохраняются на сервере; внешних интеграций нет.

## Перед публичным запуском

1. Заменить концептуальные иллюстрации реальными скриншотами и подтвердить названия, состав функций, ссылки и описания проектов. Сценарии в карточках сейчас обозначают направление будущего кейса.
2. Утвердить валюту, тарифы, границы базового объёма и правила расчёта. Добавить оценку сроков после согласования методики.
3. Добавить реальные контакты и согласованные логотипы партнёров. Партнёрский блок явно помечен как демо.
4. Для отправки заявки подключить серверный обработчик или CRM, добавить контакты посетителя, обработку ошибок и необходимые тексты о персональных данных. Сейчас кнопка действительно скачивает расчёт и не имитирует отправку.
5. Указать реальный домен, canonical, Open Graph-изображение, sitemap и правила индексации. Для поискового продвижения отдельных кейсов и статей желательно генерировать отдельные статические HTML с их метаданными: текущие detail-страницы заполняются JavaScript.

## Проверено

Проверки Chromium: калькулятор, состав и содержимое скачанного файла, сравнение стилей, пять этапов, фильтры, шесть проектов, три статьи, неизвестный ID проекта, мобильное меню и Escape. Проверено отсутствие горизонтального переполнения главной, портфолио, блога, проекта и статьи при ширинах 375/768/1440 px. Ошибок JavaScript не обнаружено. Поддерживается prefers-reduced-motion и управление этапами стрелками/Home/End.
